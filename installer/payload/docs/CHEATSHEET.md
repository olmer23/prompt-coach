# Шпаргалка Prompt Coach (1 страница)

## Формула промпта
**Роль + Задача + Контекст + Ограничения + Критерий успеха**
```
Ты senior-разработчик. Исправь handleSubmit в src/Login.tsx (React).
Не меняй стили/API. Критерий: npm test проходит.
```

## Команды
| Команда | Действие |
|---|---|
| `/coach` | Панель |
| `/coach <текст>` | Анализ текста |
| `/coach tutorial` | Обучение |
| `/coach help` | Справка |
| Панель: e / r / s / esc | edit / apply improved / send / close |

## Задача → модель
| Задача | Модель |
|---|---|
| Форматирование, переименование | DeepSeek Flash / GLM Flash |
| Тесты, документация | DeepSeek Flash |
| Фичи, багфиксы | Sonnet / MiniMax M3 |
| Архитектура | Opus / GPT Pro |

## 5 правил экономии
1. Одна задача за промпт.
2. Сужай контекст.
3. Дешёвая модель для рутины.
4. /undo вместо регенерации.
5. Короткий системный промпт.
