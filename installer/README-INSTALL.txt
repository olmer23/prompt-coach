Prompt Coach — установщик для Windows
=====================================

1. Распакуйте этот архив в любую папку.
2. Двойной клик по install.cmd.
3. Дождитесь сообщения «ГОТОВО».
4. Запустите OpenCode и введите /coach.

Что делает установщик
---------------------
- Копирует плагин в C:\Users\Public\OpenCodePlugins\prompt-coach
  (путь без кириллицы — это важно для OpenCode Desktop).
- Устанавливает зависимости. Нужен интернет; если Node.js не найден,
  установщик сам скачает portable Node.js.
- Прописывает плагин в глобальный конфиг OpenCode.
- Проверяет установку.

Если OpenCode уже был запущен
-----------------------------
Перезапустите его или выполните /reload.

Проверка
--------
В OpenCode введите /coach — должна открыться панель Prompt Coach.

Лог
---
%TEMP%\prompt-coach-install.log

Если что-то пошло не так
------------------------
Откройте лог и найдите последнюю строку с [ERROR].
Ничего вручную настраивать не нужно: установщик сам выбирает
правильную папку и сам обновляет конфиг.
