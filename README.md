# Prompt Coach

Тренажёр и живой тренер промптов для [OpenCode](https://opencode.ai): оценивает промпт по шкале
0–100 ещё до отправки, показывает, чего не хватает, подсказывает модель и экономию токенов,
и собирает улучшенную версию промпта.

В репозитории три части:

| Часть | Что это | Как запустить |
|---|---|---|
| **[trainer.html](trainer.html)** | Автономный тренажёр промптов в браузере: разбор в реальном времени, символ за символом | Открыть файл двойным щелчком — установка не нужна |
| **[opencode-guide.html](opencode-guide.html)** | Гайд по вайбкодингу с OpenCode: подключения, OpenRouter, подписки Go/Zen, модели, экономия токенов | Открыть файл в браузере |
| **[plugin/](plugin/)** + **[installer/](installer/)** | Плагин Prompt Coach для OpenCode (Desktop и TUI) с установщиком для Windows | `installer\install.cmd` |

## Быстрый старт на домашнем компьютере

### Вариант 1. Без установки — браузер

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте.
2. Откройте `index.html` (или сразу `trainer.html`) двойным щелчком.

Если в репозитории включён GitHub Pages, всё работает по ссылке без скачивания:
**https://USERNAME.github.io/prompt-coach/**

### Вариант 2. Плагин в OpenCode (Windows)

1. Скачайте ZIP и распакуйте целиком (важно: установщик ищет папку `payload` рядом с собой).
2. Запустите `installer\install.cmd` двойным щелчком.
3. Дождитесь строки **ГОТОВО**.
4. Перезапустите OpenCode и введите `/coach`.

Что делает установщик:

- копирует плагин в `C:\Users\Public\OpenCodePlugins\prompt-coach` — путь без кириллицы,
  иначе OpenCode Desktop не загружает плагин;
- ставит зависимости через npm, а если Node.js не найден — скачивает portable-сборку;
- аккуратно дописывает плагин в глобальный конфиг OpenCode (`merge-config.mjs`);
- проверяет, что OpenCode видит плагин.

Лог установки: `%TEMP%\prompt-coach-install.log`.

### Вариант 3. Клонирование

```bash
git clone https://github.com/USERNAME/prompt-coach.git
cd prompt-coach
```

Дальше — `index.html` в браузере или `installer\install.cmd` для плагина.

## Что умеет плагин

- **Оценка 0–100** в реальном времени в композере: `Coach 72/100 · модель`.
- **Чего не хватает** — конкретные пропуски по категориям: контекст, рамки задачи,
  критерии успеха, ограничения, ясность, токены.
- **Рекомендуемая модель** из каталога 36 моделей (Zen, Go, OpenRouter Free) — с ценой
  за 1M токенов, размером контекста и назначением.
- **Улучшенный промпт** одним нажатием: бесплатный шаблон или переписывание вашей текущей моделью.
- **Экономия токенов** — подсказки, как сократить промпт без потери смысла.
- **`/usage`** — лимиты OpenCode Go (5 часов / неделя / месяц), бюджеты, лимиты моделей.

### Команды

| Команда | Действие |
|---|---|
| `/coach` | Открыть панель тренера |
| `/coach <ваш промпт>` | Разобрать текст в панели |
| `/coach improve <ваш промпт>` | Переписать и вставить в композер |
| `/usage` | Лимиты и бюджеты |
| `/coach tutorial` | Обучение из 5 шагов |
| `/coach help` | Краткая справка |

В OpenCode Desktop кнопки доступны мышью: пилюля **Coach** над композером, пункт в заголовке
или **+ → Prompt Coach** в панели сессии.

## Структура репозитория

```
.
├─ index.html            стартовая страница со ссылками на оба приложения
├─ trainer.html          тренажёр промптов (автономный, без зависимостей)
├─ opencode-guide.html   гайд по вайбкодингу
├─ plugin/               исходники плагина (TypeScript)
│  ├─ src/core/          чистый анализ промптов: правила, оценка, модели, токены
│  ├─ src/index.ts       серверная часть: агентские инструменты, хук, команды
│  ├─ src/tui.tsx        панель и живая строка для терминала
│  ├─ src/gui.tsx        интерфейс OpenCode Desktop
│  ├─ dist/              собранный GUI-бандл (gui-experimental.cjs)
│  ├─ docs/              гайд, шпаргалка, конфиг, архитектура
│  └─ tests/             тесты анализатора
└─ installer/            установщик для Windows
   ├─ install.cmd        точка входа (двойной щелчок)
   ├─ install.ps1        логика установки
   ├─ merge-config.mjs   аккуратное обновление opencode.jsonc
   └─ payload/           снимок plugin/ для установки (без dev-зависимостей)
```

`installer/payload/` — упакованная копия `plugin/` без dev-зависимостей и без
`package-lock.json`: установщик ставит только то, что нужно для работы.

## Разработка

```bash
cd plugin
npm install
npm test            # тесты анализатора (node:test + tsx)
npm run typecheck   # tsc --noEmit
npm run build:gui   # пересборка dist/gui-experimental.cjs после правок src/gui.tsx
```

Требования: Node.js 20+ (для установщика не обязателен — он скачает portable-сборку),
Windows 10/11 для `install.cmd`.

Документация для разработки и для ИИ-агентов: [plugin/AGENTS.md](plugin/AGENTS.md),
