# Prompt Coach — учебник с нуля

Этот учебник научит пользоваться плагином, даже если вы никогда не писали промптов.

## Часть 1. Первые 10 минут

### 1. Зачем улучшать промпт
Плохой промпт: «сделай кнопку». Агент не знает где, какую, зачем — потратит токены на догадки.
Хороший промпт отвечает на 5 вопросов: **Кто? Что? Где? Чего нельзя? Как проверить?**

### 2. Установка
Плагин уже установлен глобально и активен. В Desktop он показывается как
`prompt-coach` (server + tui + gui) в `opencode plugin list`.
Если плагин не виден — перезапустите Desktop и выполните `/reload`.
Проверка: `opencode api get /api/command` должен содержать `coach`.

### 3. Первая проверка (Desktop)
Введите в поле ввода:
```
/coach сделай форму входа
```
Откроется панель справа. Над полем ввода появится живая пилюля `Coach 25/100 · …`,
она обновляется по мере набора текста. В панели нажмите **Apply to composer** —
улучшенный промпт заменит черновик до отправки.

### 4. Score и цвета
- **80–100 (зелёный)** — можно отправлять.
- **50–79 (жёлтый)** — работает, но лучше дополнить.
- **0–49 (красный)** — агент будет гадать. Дополните.

## Часть 2. Ежедневная работа

### 5. Live-строка
Над полем ввода видна строка `Coach 72 · Код → Kimi K2.7 Code · ~340 tok`.
Она обновляется после каждого сообщения. `/coach` — открыть панель.

### 6. Как читать подсказки
«Укажите конкретный файл (src/...)» = добавьте путь, например `src/components/Login.tsx`.
Каждая подсказка — это действие, а не теория.

### 7. Кнопки панели
- **✨ Improve with LLM → Apply** — один клик: LLM переписывает промпт и вставляет в composer.
- **Apply template** — бесплатный шаблон с секциями.
- **Apply improved** — применить текущий вариант.
- **Copy** — копировать исходный.
- **Usage** — лимиты Go.
- **Help** — все функции и туториал внутри панели.
- В TUI: **e** edit · **r** template · **l** LLM improve · **s** send · **esc** close.

### 8. Выбор модели
Плагин определяет тип задачи и советует 2 варианта: **подходит** (лучший под задачу) и
**дешевле / резерв**. Цена показывается за 1M токенов, рядом — **ум** (0–100) и **выгода**
(ум на доллар, 0–100), а также месячный лимит Go для модели.

| Задача | Подходит | Дешевле / резерв |
|---|---|---|
| Архитектура, план | DeepSeek V4.1 Flash | GLM-5.3 (умнее) |
| Написание кода | Kimi K2.7 Code | DeepSeek V4.1 Flash |
| Отладка, баги | DeepSeek V4.1 Flash | DeepSeek V4 Pro (тупик) |
| UI, скриншоты | Gemini 4 Argon | GLM-5.3-Flash |
| Быстрая правка | GLM-5.3-Flash | GPT-6 Luna |
| Большой файл / вывод | MiniMax M3.1 Flash | MiniMax M3 |
| Кончились лимиты Go | North Mini Code (free) | Big Pickle |

Флагманы (Kimi K3.1 Pro, Grok 4.7, DeepSeek V4 Pro) — только для сложной архитектуры и
тупиков в отладке: у них маленький месячный лимит.

### 9. Экономия токенов — 5 привычек
1. Один промпт = одна задача.
2. Только нужные файлы, не «весь репозиторий».
3. Короткий системный промпт.
4. `/undo` вместо повторной генерации.
5. Дешёвая модель для рутины.

## Часть 3. Продвинутое

### 10. Настройки
В `opencode.jsonc` через `options`: порог, язык, веса. См. `CONFIG.md`.

### 11. `/coach_rewrite` с deep=true
LLM-переписывание стоит токены. Используйте для важных/сложных промптов,
для остального хватает шаблона (клавиша **r**).

### 12. Типовые ошибки
- «Сделай всё красиво» — нет критерия.
- «Исправь баг и добавь фичу и обнови доки» — три задачи, разбейте.
- «Проанализируй весь проект» — сожжёт контекст, сузьте.
- «Улучши код» — улучшить что и по какой метрике?

## Быстрая тренировка
Откройте `trainer.html` в браузере: режим «Урок» проведёт через 5 упражнений
с живым score. Цель — набрать ≥80 в каждом.
